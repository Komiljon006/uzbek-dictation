RubaiSTT — o'zbekcha ovozli yozuv

Windows 10/11 uchun qo'llanma · v1.1 · Ctrl+Alt+D bosing, gapiring, matn o'zi yoziladi

1. Bu nima

Istalgan dasturda — Telegram, Word, Excel, brauzer, 1C, SAP — yozish maydoniga kursorni qo'yasiz, Ctrl+Alt+D bosasiz, o'zbekcha gapirasiz, yana Ctrl+Alt+D bosasiz — gapirganingiz o'sha joyga lotin alifbosida matn bo'lib yoziladi.

Internet kerak emas. Hammasi kompyuterning o'zida ishlaydi, ovoz hech qayerga yuborilmaydi. To'lov, obuna, litsenziya kaliti yo'q. Mac versiyasi bilan bir xil model (rubaiSTT v2 medium) — aniqlik bir xil.

3. O'rnatish — bitta qadam

1
RubaiSTT-Windows.zip ni yuklab oching (o'ng tugma → «Extract All» / «Barchasini chiqarish»).
2
Ochilgan papkada ORNATISH.bat ni ikki marta bosing. Qora oyna ochiladi — yopmang. U o'zi: Python → whisper dvigateli → model (823 MB) → yorliqlarni o'rnatadi. 5–30 daqiqa (internetga qarab).
3
Windows «Noma'lum nashriyotchi / Windows protected your PC» desa — «Batafsil» (More info) → «Baribir ishga tushirish» (Run anyway).
4
Oxirida «OK: O'RNATILDI» chiqadi va soat yonida yashil mikrofon belgisi paydo bo'ladi (10–40 soniya — model xotiraga yuklanadi).
Yuklash uzilib qolsa — ORNATISH.bat ni yana bosing: yuklangan qismi saqlanadi, qolganidan davom etadi.

4. Ishlatish

  1. Kursorni yozish joyiga qo'ying (Notepad'da sinab ko'ring).
  2. Ctrl+Alt+D — qisqa «bip», belgi qizil bo'ladi: yozilmoqda.
  3. Gapiring — oddiy tezlikda, mikrofondan 20–30 sm.
  4. Yana Ctrl+Alt+D — past «bip», belgi sariq: o'girilmoqda (2–6 soniya).
  5. Matn o'sha joyga yoziladi, belgi yana yashil.
Belgi rangiMa'nosi
● yashiltayyor — gapirishingiz mumkin
● qizilyozib olyapti
● sariqmatnga o'giryapti — kuting

Mikrofonni tanlash: belgi ustida o'ng tugma → Mikrofon → kerakli qurilma. Kompyuter yoqilganda dastur o'zi ishga tushadi. Ish stolida ham «RubaiSTT» yorlig'i bor.
